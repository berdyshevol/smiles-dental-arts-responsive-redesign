# Smiles Dental Arts — Responsive Redesign Demo

A modern, fully-responsive rebuild of three pages from
[cudahydentist.net](https://www.cudahydentist.net) — **Home**, **Meet the
Doctor**, and **Office Tour** — created as a proposal demo.

Keeps the practice's brand (logo, teal + gold palette, real copy & photos) while
upgrading to a clean, mobile-first layout with a working mobile nav, scroll
animations, and an interactive office gallery.

## Stack
- Next.js 16 (App Router) · React 19
- Tailwind CSS v4
- Framer Motion
- Fonts: Fraunces (display) + Plus Jakarta Sans (body)

## Run locally
```bash
pnpm install
pnpm dev
# http://localhost:3000
```

## Pages
- `/` — home (hero, services, welcome, smiles, testimonials, CTA)
- `/meet-the-doctor` — Dr. Cesar Sanchez bio + credentials
- `/office-tour` — intro + responsive lightbox gallery

> Demo only. All brand assets belong to Smiles Dental Arts.
